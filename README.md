# Gravity Leon

Play it on [itch.io](https://nikofactory.itch.io/gravity-leon) (free).

**Side A**: Leon le Cameleon races against the clock in a punishingly difficult 2D platformer. Can you top the leaderboard?

**Side B**: Gravity Leon is a documented experiment with Vibe Coding for gameplay design. See *about the code* Section below.

Gameplay video on [Youtube](https://www.youtube.com/watch?v=YKK2RJ8WRWI).

<img src="workshop/screenshots%20selection/gravity-leon-visuals.png" alt="Gravity Leon visuals" width=100%>

## Technical stuff

Requirements: C++17, raylib.

Recommendation: play with a joypad (tested with Xbox One and Logitech controllers).

Compile and Run with :
```
make run
```

Run with :
```
./gravityleon
```

## About the code

Gravity Leon has been vibecoded with Claude Code Opus 5.5 Extra High. Made in C++ with raylib and SDL GameControllerDB. 

I used a multimodal prompting approach combining...

1. lengthy text prompts, including detailed software architecture and implementation guidelines
2. hand-drawn prompts for design and gameplay (on paper and computer)
3. in-game reporting system with snapshot + user input (CTL+B in-game)

Rough estimate : about 50 hours of human work for concept, design, art and code orchestration. We composed the music a quarter of a century ago (protracker modules and mp3).
