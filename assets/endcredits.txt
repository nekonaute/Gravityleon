## About the code

Vibecoded with Claude Code Opus 5.5 Extra High
Made in C++ with raylib and SDL GameControllerDB
Method : multimodal approach combining...
  1. lengthy text prompts 
  2. hand drawn prompts (paper and computer)
  3. in-game reporting system with snapshot + user input

Rough estimate : about 50 hours of human work 
(excluding music, composed a quarter of a century ago)
